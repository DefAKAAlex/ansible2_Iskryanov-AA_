## Задание 1
**Выполните действия, приложите файлы с плейбуками и вывод выполнения.**
Напишите три плейбука. При написании рекомендуем использовать текстовый редактор с подсветкой синтаксиса YAML.

Плейбуки должны:

1. Скачать какой-либо архив, создать папку для распаковки и распаковать скаченный архив. Например, можете использовать официальный сайт и зеркало Apache Kafka.

### скачаем и распакуем Kafka
```
i-def@def-sysinfo:~/VS-Pupil/sdvps-homeworks/ansible2_Iskryanov-AA_$ ansible-playbook -i inventory.ini dwn_extr.yml

PLAY [Download_extract_Kafka] *********************************************************************

TASK [Gathering Facts] ****************************************************************************
ok: [localhost]

TASK [Create_dir] *********************************************************************************
changed: [localhost]

TASK [Download_archive] ***************************************************************************
changed: [localhost]

TASK [Extract archive] ****************************************************************************
changed: [localhost]

TASK [Del_archive] ********************************************************************************
changed: [localhost]

PLAY RECAP ****************************************************************************************
localhost                  : ok=5    changed=4    unreachable=0    failed=0    skipped=0    rescued=0    ignored=0
```

2. Установить пакет tuned из стандартного репозитория вашей ОС. Запустить его, как демон — конфигурационный файл systemd появится автоматически при установке. Добавить tuned в автозагрузку.

### установка и запуск Tuned
```
i-def@def-sysinfo:~/VS-Pupil/sdvps-homeworks/ansible2_Iskryanov-AA_$ ansible-playbook -i inventory.ini install_tuned.yml

PLAY [Tuned_inst_run] *************************************************************************************************************************************************************

TASK [Gathering Facts] ************************************************************************************************************************************************************
ok: [localhost]

TASK [Install package tuned] ******************************************************************************************************************************************************
ok: [localhost]

TASK [Start_tuned_service] ********************************************************************************************************************************************************
ok: [localhost]

TASK [Verify_run] *****************************************************************************************************************************************************************
ok: [localhost]

TASK [Show_status] ****************************************************************************************************************************************************************
ok: [localhost] => {
    "msg": "Tuned service is active"
}

PLAY RECAP ************************************************************************************************************************************************************************
localhost                  : ok=5    changed=0    unreachable=0    failed=0    skipped=0    rescued=0    ignored=0
```

3. Изменить приветствие системы (motd) при входе на любое другое. Пожалуйста, в этом задании используйте переменную для задания приветствия. Переменную можно задавать любым удобным способом.

### изменяем MOTD

```
i-def@def-sysinfo:~/VS-Pupil/sdvps-homeworks/ansible2_Iskryanov-AA_$ ansible-playbook -i inventory.ini change_motd.yml

TASK [Gathering Facts] ********************************************************************************************************************************************************************
ok: [localhost]

TASK [Set MOTD] ***************************************************************************************************************************************************************************
ok: [localhost]

TASK [Ensure SSH uses MOTD] ***************************************************************************************************************************************************************
ok: [localhost]

PLAY RECAP ********************************************************************************************************************************************************************************
localhost                  : ok=3    changed=0    unreachable=0    failed=0    skipped=0    rescued=0    ignored=0

i-def@def-sysinfo:~/VS-Pupil/sdvps-homeworks/ansible2_Iskryanov-AA_$ cat /etc/motd
Hello in brainless world
```
